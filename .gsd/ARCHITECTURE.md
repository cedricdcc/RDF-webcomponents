- **Location:** `src/app/`, `src/components/`, `src/hooks/`, `src/lib/`

### RDF Webcomponents Core Library
- **Purpose:** Framework-agnostic web components that handle RDF data orchestration, visualization, and fetching.
- **Location:** `src/rdf-webcomponents/`
- **Dependencies:** Lit, n3, rdf-lens, wrx, streaming parsers (JSON-LD, RDFa, RDF/XML).

### Core Web Workers
- **Purpose:** Offloads heavy RDF parsing, SPARQL querying, and data fetching from the main thread.
- **Location:** `src/rdf-webcomponents/core/worker/`
- **Dependencies:** Fetch API, RDF parsers.

## Data Flow

1. User interacts with the UI (Next.js App or directly with the Web Components).
2. The web components (e.g., `source-rdf`, `link-orchestration`) dispatch fetch operations for RDF sources or shapes to the Core Workers.
3. Core Workers fetch the remote data (HTTP GET/POST) and use streaming parsers to parse the data into RDF quads.
4. Data is processed or queried (via SPARQL/Shapes) and passed back to the main thread.
5. `lens-display` or custom UI elements render the resulting semantic data.
